Reads the text stored inside compiled Luau or Lua files and runs the risk check on it. It cannot turn bytecode back into source code.

The tools live in core.js. Load it on any page, or in Node, and call them directly.

In a web page

<script src="core.js"></script>
<script>
  const r = LuaScriptFucker.cleanup(code, { fmt: false });
  console.log(r.code, r.stats);
</script>

In Node

const { cleanup, scan, inspect, bytecode } = require('./core.js');
const report = scan(code);
console.log(report.level, report.score, report.findings);

What each function returns

  • cleanup(code, options) gives { code, stats }. Options: chr esc cat hex ren b64 fmt, each true or false.
  • scan(code) gives { level, score, findings, urls }. Level is high, medium or none. Score is 0 to 100.
  • inspect(code) gives { strings, urls, calls }, each sorted by how often it appears.
  • bytecode(bytes) takes a Uint8Array and gives { kind, version, size, parsed, strings }.
