Reads the code without running it.

Pulls out links, text and function calls.

The tools live in core.js. Load it on any page, or in Node, and call them directly.

In a web page

<script src="core.js"></script>
<script>
  const r = LuaScriptFucker.cleanup(code, { fmt: false });
  console.log(r.code, r.stats);
</script>

In Node

const { cleanup, scan, inspect } = require('./core.js');
const report = scan(code);
console.log(report.level, report.findings);

What each function returns

  • cleanup(code, options) gives { code, stats }. Options: chr esc cat hex fmt, each true or false.
  • scan(code) gives { level, findings, urls }. Level is high, medium or none.
  • inspect(code) gives { strings, urls, calls }, each sorted by how often it appears.
