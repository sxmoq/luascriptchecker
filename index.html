Reads the text stored inside compiled Luau or Lua files and runs the risk check on it. It cannot turn bytecode back into source code.

The tools live in core.js. Load it on any page, or in Node, and call them directly.

In a web page

<script src="core.js"></script>
<script>
  const d = LuaScriptFucker.dump(code);
  console.log(d.verdict.title, d.says, d.findings);
</script>

In Node

const { dump, scan, cleanup, inspect, bytecode } = require('./core.js');
const report = dump(code, { remote: { 'https://example.com/raw/x': 'script text' } });
console.log(report.verdict, report.pending);

What each function returns

  • dump(code, { remote }) gives the full report: verdict (state, title, advice), says (plain sentences), pending (linked scripts still to read), gates (protected loaders), findings, loaders, layers, obfuscation, strings, calls, iocs and meta. Pass downloaded script text in remote, keyed by link, to have it checked too.
  • scan(code) gives { level, score, findings, urls }. Level is high, medium or none.
  • cleanup(code, options) gives { code, stats }. Options: chr esc cat hex ren b64 fmt, each true or false.
  • inspect(code) gives { strings, urls, calls }.
  • bytecode(bytes) takes a Uint8Array and gives { kind, version, size, parsed, strings }.
Saved only in this browser. The last 20 runs are kept.
